# Contributing to /dreaming

Everything under `src/content/dreaming/` auto-indexes at build time. Drop a file in,
commit, push to `master` — GitHub Actions rebuilds and deploys. No config to touch.

This README is excluded from the index (see `src/lib/content.js`).

## What indexes

- Extensions: `.md`, `.pdf`, `.html`. Anything else is ignored.
- Folder name is the label:
  - `YYYY-MM` folders (e.g. `2026-02/`, `2026-11/`) become dated sections on the
    dreaming page, newest first. **Put dated notes here so they label correctly.**
  - Any other folder (`textbook/`, `coursework/`, ...) collapses under "others".
  - Root-level files land in "others → root".
- Titles:
  - `.md` → first `# heading` in the file (fall back to filename)
  - `.html` → the `<title>` tag (fall back to filename)
  - `.pdf` → filename

## How each type is served

- `.md` renders to a page at `/dreaming/<slug>` (slug = path under this dir, no extension)
- `.pdf` and `.html` are copied verbatim at build time to
  `/content/dreaming/<slug>.<ext>` and linked directly from the index.
  Standalone interactive HTML pages (itineraries, tools, widgets) go this route.

## Steps

1. Put the file in the right subfolder, e.g. `src/content/dreaming/2026-11/your-note.md`
2. `git add` + commit + push to `master`
3. Site deploys automatically (`.github/workflows/nextjs.yml`)

Never commit `public/content/` — it is generated by `scripts/sync-pdfs.mjs` at build
time and gitignored. `npm run build` (or `npm run dev`) regenerates it.
